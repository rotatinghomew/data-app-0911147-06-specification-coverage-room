# 分析资料与解释边界

## 测量语义
measurements 的 qualifier 为 exact、below 或 above，value 对非 exact 行是检测界而非真实值。attribute 的 unit 与 specifications 匹配；batch 是生产批次而非自动独立的随机样本。未来声明要说明目标是当前批次还是批次混合总体。
## 正确的承诺
区分均值的置信区间、个体预测范围和具有置信保证的总体覆盖容忍范围。方法由开发者选择并说明假设；无法支持指定覆盖与置信程度时应解释原因，不按请求强行缩窄区间。逐项、多项同时与多维联合覆盖不能混用。
## 独立检查
完整独立观测下一侧样本最大值覆盖比例 p 的分布自由置信度为 1-p**n；可用于核对小样本可行性，而非强制全部场景采用该方法。常数、单位转换、偏斜、截断及重复批次资料均在 analysis_cases。没有足够尾部信息时允许部分识别的覆盖界。

## 已实现方法（tolerance 操作）
- 正向声明（mode=claim）：给定覆盖比例 p 与置信程度 γ，用分布自由次序统计量构造容忍界。置信度只依赖秩次：单侧上界 X_(s) 的“覆盖≥p”置信度为 P(Bin(n,p)≤j−1)，j 为该界在全体真值中的秩；下侧界对称；双侧 [X_(r),X_(s)] 为 P(Bin(n,p)≤j2−j1−1)。检测限记录不当真实读数：其真实秩未知，按使结论最保守的秩处理；确定落在界内的删失（如检测上限不超过候选上界）计入界内计数。样本量不足时明说无法支持，给出该置信度下可支持的最大覆盖比例与最优情形参考样本量，不按请求缩窄区间。
- 反向规格（mode=spec）：规格界限固定（可用 specs 覆盖），逐条记录分为确定在内、确定在外、无法判定（检测限）。覆盖比例置信下界取 Clopper–Pearson（只计确定在内）；上界把无法判定全部算作在内，即部分识别界。
- 逐项、同时与联合：逐项结果各自成立；多项同时成立用 Bonferroni（每项需达 1−(1−γ)/m）；多维联合覆盖按同一样品同时满足全部规格计数，不假设维度独立。边际覆盖份额相乘仅在维度独立时成立，结果中仅作对照，不作证据。
- 正态参考区间（Howe 双侧近似 / 非中心 t 单侧）只在没有检测限记录时给出，标注假设未验证、偏度大时警告；它不参与任何“支持”判定，存在删失时不计算（不以检测限代替真实值）。
- 目标总体为批次混合总体；批次是生产批次而非随机样本，结论不外推至未观测批次。偏斜分布不影响分布自由置信度的有效性，只影响区间效率。
