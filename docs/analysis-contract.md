# 分析资料与解释边界

## 测量语义
measurements 的 qualifier 为 exact、below 或 above，value 对非 exact 行是检测界而非真实值。attribute 的 unit 与 specifications 匹配；batch 是生产批次而非自动独立的随机样本。未来声明要说明目标是当前批次还是批次混合总体。
## 正确的承诺
区分均值的置信区间、个体预测范围和具有置信保证的总体覆盖容忍范围。方法由开发者选择并说明假设；无法支持指定覆盖与置信程度时应解释原因，不按请求强行缩窄区间。逐项、多项同时与多维联合覆盖不能混用。
## 独立检查
完整独立观测下一侧样本最大值覆盖比例 p 的分布自由置信度为 1-p**n；可用于核对小样本可行性，而非强制全部场景采用该方法。常数、单位转换、偏斜、截断及重复批次资料均在 analysis_cases。没有足够尾部信息时允许部分识别的覆盖界。
